VR comfort and cleanup pass (2026-11-19; supersedes prior grip offsets)
- User hardware feedback: accidental/abrupt forward motion, difficult stopping, incorrect grip angle, excessive HUD.
- Hands now need an open palm for propulsion. Stroke input needs 0.12 s / 5 cm of deliberate movement; speed threshold 0.55 m/s. Tracking-space palm velocity prevents head motion from becoming a fictitious stroke; reject discontinuous tracking samples.
- Glide requires actual outward hand travel from a retracted pose, >55 cm reach, forward placement, finger alignment, low hand speed and 0.7 s hold. Its target ramps over 1.1 s; acceleration is filtered and capped. Maximum hand-swim speed 1.6 m/s, with faster natural stopping. Controller locomotion remains unchanged.
- Both tracked empty fists immediately set velocity and pending acceleration to zero. Brake stays latched after opening fists. A new qualified stroke, or retract-then-extend glide, is required to restart. Existing forward palm push still provides backward thrust.
- Grip geometry explicitly approved by user: grip point = palm + palm-local -Y * 0.03 m; adjusted pinch midpoint = raw midpoint + palm-local +Y * 0.03 m. Handle direction uses these two shifted points. Palm orientation still resolves roll. Pinch detection uses raw fingertips.
- VR HUD removes persistent objective/help/aim overlays and routine tool pickup/release hints. Objectives/controls remain accessible in the existing journal. Existing progress arc is reused at 8.8 cm on the inner side of the active tool hand: left hand -> right side; right hand -> left side. Show only while contacting a correct cleaning target (plus brief completion fade), hide on tracking loss/no tool/UI menus.
- Checks passed: compile; controlled motion tests for gradual start, speed cap, faster natural stop, same-sample fist braking, persistent stopped state after release, explicit restart, no head-motion propulsion or sideways/misaligned glide, and backward thrust. Live HUD fixture verified both tools in both hands, scale/side/visibility and removal of routine hints. Revised grip geometry, gesture distinctions and XRI release checks passed.
