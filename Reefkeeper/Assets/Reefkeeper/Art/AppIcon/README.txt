REEFKEEPER / THREE-LAYER APP ICON STUDY
SELECTED: WITH HELMET (user choice, 2026-11-16). Root PNGs are the selected three layers and preview.

WithHelmet and WithoutHelmet each contain:
icon_bg.png: opaque blue background, 1024 square, sRGB values
icon_fg2.png: four stickers captured from actual mature coral prefabs
icon_fg3.png: actual Lucky Cat head, with/without original glass and brass ring
preview.png / preview_128.png: flat review composites, not extra layers

Foregrounds remain within the inscribed circle; exact extents are in artifacts/icon-review/validation.txt. No additional fake shadows or system glints are baked into layers.
The helmet has genuine semitransparent pixels. PICO recommends crisp foreground silhouettes and discourages semitransparent highlights/shadows: treat WithHelmet as an exploratory comparison, not a validated submission asset. The user selected WithHelmet for its diving identity. Keep its genuine transparency; validate its treatment in the target launcher before final submission. WithoutHelmet remains an unselected comparison.
Only image assets are prepared; PlayerSettings, SDK packages and Android manifests have not been changed. Current project uses PICO Unity Integration SDK 3.4.0; the documented Icon Configurator belongs to SDK 6.1.x. Device/SDK integration is pending.
