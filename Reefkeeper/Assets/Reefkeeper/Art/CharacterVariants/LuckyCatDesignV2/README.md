# Lucky Cat Design V2

Open LuckyCat_DesignV2.prefab in Prefab Mode. In LuckyCatEyeExpressions, Sparkle uses the two independently traced PNGs from the approved front view. The positive-X eye uses Eye_ScreenLeft, the negative-X eye uses Eye_ScreenRight. Happy, Blink and Sad share the existing expression artwork across both eyes. Returning to Sparkle reads each eye's own material.

The variant inherits the original body Animator and uses larger ears, a pink heart nose and a white, fuller muzzle. The Unity menu Reefkeeper > Art > Build Lucky Cat Design V2 can regenerate the variant. Asset references have been checked offline. The variant still needs an in-editor visual check.
