LuckyCatStamp.png is a monochrome ink treatment of a Unity orthographic capture
of Assets/Reefkeeper/Prefabs/CatShop/LuckyCat.prefab, viewed from +Z.
The existing model and its materials supply all character shapes and details.
No AI-generated character art is used. Render size: 512 x 512, transparent.
Ink alpha = source alpha * (0.12 + 0.88 * (1 - luminance)^1.3).
Refresh the stamp if the in-game shopkeeper model changes.
